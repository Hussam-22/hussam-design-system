# Extraction scope

The catalog covers distinct reusable visual effects and component patterns, including each of the five service illustration variants. Semantic site sections (hero, about, contact, work, knowledge and platforms) are compositions of these patterns, not separate reusable skills. Header/footer navigation and locale routing belong to the consuming application. Case-study copy, project/client captures, portrait, inactive software-products story and personal profile links are intentionally not part of a component library.

Astro-specific vector components were adapted to React. Spotlight, device frames/comparison, carousel, headings, theme control, project card and contribution chart have portable APIs. Scroll reveal uses native Web Animations; timeline retains GSAP. ProductSystem is static in the library. Chat and dashboard retain local demonstration behavior; they are not production backends.

Every catalog entry identifies its exact source, integration notes and preview. The TechText entry is explicitly a recipe because upstream restrictions prevent library redistribution.
