# Interactive technical text (upstream recipe)

The portfolio customized the ReactBits TechText component. Its current MIT + Commons Clause license restricts redistributing the components themselves, including ported bundles. This component-only repository therefore contains an integration skill and visual reference, but no TechText implementation or package export.

Install directly into your application using the official registry instructions at https://reactbits.dev/text-animations/tech-text. Inspect the current license at https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md. Use its TypeScript CSS variant and keep upstream notices.

Portfolio configuration: Inter Tight Variable, weight 720, letterSpacing -0.064, reach 150, strokeWidth 1.5, specks 12, sweep true, speed 1. Light gradient #7941a0/#a73880/#a95425, dark gradient #b697fa/#efa1d0/#ffc293. Dragging requires a fine pointer. Reduced motion renders semantic static gradient text. Arabic requires joined word shaping, letterSpacing 0 and area reveal; disable per-letter labels/selection.
